Container-only shared swarm workbench. Read docs {"name":"swarm"} for typed API examples and limits. Default Python RLIMIT_NPROC=1 restricts subprocesses; use the existing bash tool for Git/tests/external commands under its configured policy, and Python for in-process work/board coordination. Do not raise limits from agent code. First create a run with goal, constraints, explicit command/review criteria, 1–10 total in-container members (coordinator included), and a Unix wall-clock deadline within seven days. Then establish a fixed pool with existing spawn/agent_cmd; use local spawn inside this shared container. Idle and reserved members count. Never launch nested containers to reset the cap.
Use op=run with exactly one of code/path. On a wake hint, first use op=summary. If terminal, do not execute Python for inbox/ack; report the summary and remain available for supervisor requests/artifact export.
