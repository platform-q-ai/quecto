# quecto board

This branch holds the project's board: one markdown file per artifact, each in
its kind's folder: `tasks/<id>.md`, `plans/<task>.<n>.md`, `runs/<task>.<n>.md`,
`changes/<task>.<n>.md`, `reviews/<task>.<change>.md` and `discussions/<id>.md`,
with `format/board` naming the format and `archive/` kept for archived work. It is
written only by quecto's board operations; do not edit, merge or rebase it by hand.
If a hand edit breaks it, move `quecto/board` back to the commit before that edit.
