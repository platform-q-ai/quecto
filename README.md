# Quecto Workspace

This repository is a Cargo workspace containing the Quecto agentic harness and related packages.

Current version: **0.91.4**

## Packages

| Package | Path | Description |
|---|---|---|
| `quecto` | [`quecto-agentic-harness/`](quecto-agentic-harness/) | Agentic harness and core CLI/UDS agent |
| `quecto-tui` | [`quecto-tui/`](quecto-tui/) | Terminal UI client |
| `quecto-api` | [`quecto-api/`](quecto-api/) | HTTP/WebSocket gateway |
| `quecto-mcp` | [`quecto-mcp/`](quecto-mcp/) | MCP extension bridge |
| `quecto-runtime-manager` | [`quecto-runtime-manager/`](quecto-runtime-manager/) | Runtime manager |

Package-specific source, tests, docs, and fixtures are colocated under each package root.
